# 原型交互规范

## 1. 导航与页面切换

- 本项目没有 Vue Router，页面切换由 `App.vue` 的 `activeId` 和 `registry.ts` 完成。不要为了深链或菜单结构引入 `vue-router`，除非用户明确要求并确认影响范围。
- 侧栏按需求目录分组，同一时间只展开一个分组；系统设置固定在侧栏底部。
- 页面标题来自文件名，分组名来自一级目录；不要在页面内再维护一份菜单数据。
- 新页面默认隐藏。必须通过「系统设置」打开后才会出现在导航中。
- 当前页被隐藏时，应用自动回到系统设置；这是现有行为，不要改成停留在空白页。
- 当前页不写入 URL，刷新后回到系统设置；不要声称原型支持深链。
- 需求内跨页跳转使用 `src/composables/useWorkbenchNavigation.ts` 的 `openPage(id)`；返回 `false` 表示目标页未显示，必须给出明确提示，不要静默无反应。
- 返回系统设置使用同一组合函数里的 `openSettings()`；不要用 toast 伪装成已跳转。
- 业务原型页不写页面级大标题；用工具栏左侧的视图名称、数量和操作表达上下文。

## 2. 需求显隐与验收

- 单个页面用系统设置里的 `Switch` 控制显隐；开关状态写入 `localStorage` 的 `prototype-workbench-visible-pages`。
- 需求验收后，关闭该需求全部页面的开关，并在 `requirement.json` 中标记 `accepted`；不要删除页面。
- 不要新增第二套显隐机制（例如 URL 参数、单独的配置文件或后端状态）来绕开系统设置。
- 需求详情页可以只读展示页面的「显示中 / 已隐藏」状态，并引导到系统设置；不要在详情页再放一组显隐开关。
- 不要自动显示新页面，也不要在没有用户操作的情况下批量打开页面。
- 显隐状态只存在当前浏览器；更换浏览器后全部隐藏是预期行为，不是 bug。

## 3. 弹窗与抽屉

- 业务交互使用页面内弹窗或抽屉，不使用 `window.alert` / `confirm` / `prompt`。
- 结构：遮罩 + 面板 + 标题 + 内容 + 底部操作；宽度 480px（简单确认）或 640px（表单），移动端接近全宽。
- 主操作放在右下角，次操作在左；危险操作使用 `danger`，文案写清对象和后果。
- 打开后焦点进入面板，`Esc` 关闭，关闭后焦点回到触发按钮。
- 点击遮罩关闭仅适用于非破坏性弹窗；表单有未保存内容或危险确认时不要点击遮罩即关闭。
- 弹窗内不要嵌套另一个弹窗；需要多步时使用分步内容或抽屉。

## 4. 表单

- 标签放在控件上方；必填项有明确标记；说明文字放在控件下方。
- 输入框、选择器、开关使用统一高度和圆角；同一行控件对齐。
- 校验时机：失焦或提交时校验；错误信息紧跟控件，不要只弹 toast。
- 提交中禁用提交按钮并显示加载态；失败时保留用户输入，不清空表单。
- 成功提交后给出明确反馈，并关闭弹窗或更新列表；不要假装成功。
- 需求 ID 使用 `REQ-XXXX` 格式；提交前做格式校验，避免创建无法归属的原型。

## 5. 列表、卡片与表格

- 列表工具栏包含搜索、筛选和主操作；结果数量可见。
- 卡片按「标识/状态 → 标题 → 描述 → 元信息 → 操作」组织；整卡可点击时，内部按钮要阻止冒泡。
- 表格表头不换行，行高紧凑，操作列固定在右侧；窄屏允许横向滚动。
- 空列表显示空状态和下一步操作，不要只显示一行「暂无数据」。
- 搜索和筛选无结果时，保留筛选条件并提供清除入口。
- 不要在列表里放多层嵌套卡片或重复的页面标题。

## 6. 加载、空状态与错误

- 页面异步加载使用现有的 `Suspense` 占位；不要出现无反馈的空白。
- 超过 300ms 的操作显示加载态；按钮加载时禁止重复提交。
- 空状态包含图标、原因和操作；错误状态包含原因和可执行的下一步。
- 错误信息不显示堆栈、绝对路径、令牌或内部实现细节。
- 不要用隐藏错误、伪造成功或自动重试来掩盖失败。

## 7. Mock 数据与模拟交互

- 原型默认不连接后端；所有数据来自需求目录内的本地 Mock。
- Mock 数据必须确定、可重复；不使用真实令牌、真实客户信息或外部接口。
- 模拟操作要有真实反馈：状态变化、toast、列表更新或空状态；不要点击后无反应。
- 页面明显是演示态时，在工具栏加低对比的「演示数据」标记。
- 需要持久化的演示状态使用带需求前缀的 `localStorage` key；不要复用外壳的显隐 key。
- 除非页面本身在演示持久化，刷新后重置是预期行为。

## 8. 键盘与可访问性

- 所有交互可用键盘完成；`Tab` 顺序与视觉顺序一致。
- 图标按钮有 `aria-label`；开关有可读 `label`；当前导航项有 `aria-current`。
- 焦点样式清晰可见；不要只靠颜色表达状态，状态标签同时提供文字。
- 动画时长不超过 250ms，并尊重 `prefers-reduced-motion`。
- 移动端导航使用现有抽屉模式；遮罩可关闭，关闭按钮有明确标签。

## 9. 交互自检清单

- 从系统设置打开页面后，导航出现且能进入。
- 分组展开/收起正常，当前页高亮正确。
- 隐藏当前页后回到系统设置，不出现空白。
- 弹窗可用 `Esc` 关闭，焦点返回触发元素。
- 表单校验、提交中禁用、失败保留输入。
- 搜索/筛选有结果和无结果两种状态都正常。
- 窄屏下侧栏、表格和弹窗不溢出。
- 浏览器控制台没有报错和未处理异常。
