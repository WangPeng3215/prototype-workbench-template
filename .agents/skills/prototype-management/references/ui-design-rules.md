# 原型 UI 设计规范

## 1. 设计方向

- 轻量、紧凑、克制的桌面工作台风格，信息密度优先，不做营销页式大留白和大装饰。
- 以白色卡片、浅灰蓝背景、低对比边框为主；主色只用于主操作、选中态和关键状态。
- 业务原型页面不写页面级大标题和副标题；页面上下文放在工具栏、卡片标题或面包屑中。外壳的系统设置页属于基础设施页面，不受此条限制。
- 视觉一致性优先于局部创意。新页面必须能看出和现有外壳、系统设置页属于同一套产品。

## 2. 设计 Token

Token 定义在 `src/style.css` 的 `:root`。新增代码优先使用 Token；修改旧页面时不要为了替换硬编码值而做无关重构。

### 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--primary` | `#4f6ef7` | 主操作、选中态、链接 |
| `--primary-foreground` | `#ffffff` | 主色背景上的文字 |
| `--primary-soft` | `#edf1ff` | 选中背景、主色浅底 |
| `--background` | `#f5f7fb` | 页面背景 |
| `--card` | `#ffffff` | 卡片、面板 |
| `--text-primary` | `#242a3a` | 标题、主要文字 |
| `--text-secondary` | `#555e70` | 常规正文 |
| `--text-tertiary` | `#929aac` | 辅助说明、占位 |
| `--border` | `#e5e9f1` | 常规边框 |
| `--border-subtle` | `#e9edf4` | 分隔线、弱边框 |
| `--success` / `--success-soft` | `#34c759` / `#eaf9ef` | 成功、已验收 |
| `--warning` / `--warning-soft` | `#f5a623` / `#fef5e7` | 待处理、待验收 |
| `--danger` / `--danger-soft` | `#f56c6c` / `#fdeeee` | 错误、删除、危险操作 |
| `--info` / `--info-soft` | `#8e8ea0` / `#f2f2f6` | 中性状态、归档 |

- 不新增品牌色、渐变背景或高饱和装饰色。
- 状态色只表达状态，不用来装饰普通卡片。
- 正文与背景的对比度至少满足 WCAG AA；浅色文字不得低于 `--text-tertiary`。

### 间距

| Token | 值 | 典型用途 |
| --- | --- | --- |
| `--space-1` | `4px` | 图标与文字、紧凑间隔 |
| `--space-2` | `8px` | 控件内间距、按钮组 |
| `--space-3` | `12px` | 卡片内小分组 |
| `--space-4` | `16px` | 卡片内边距、表单行 |
| `--space-5` | `20px` | 页面区块间距 |
| `--space-6` | `24px` | 页面左右内边距 |
| `--space-8` | `32px` | 大区块间距 |

- 页面左右内边距 20–30px；卡片内边距 14–18px；工具栏高度 48–56px。
- 列表行高 44–58px；表头不换行；不要把表单控件做成 28px 以下的可点击高度。

### 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | `6px` | 标签、小控件 |
| `--radius-md` | `8px` | 按钮、输入框 |
| `--radius-lg` | `11px` | 卡片、面板 |
| `--radius-pill` | `999px` | 胶囊标签、头像 |

### 字号与字重

| Token | 值 | 用途 |
| --- | --- | --- |
| `--font-size-2xs` | `10px` | 辅助元信息、路径 |
| `--font-size-xs` | `11px` | 说明、状态 |
| `--font-size-sm` | `12px` | 卡片正文、表格辅助 |
| `--font-size-md` | `13px` | 导航、卡片标题 |
| `--font-size-base` | `14px` | 常规正文 |
| `--font-size-lg` | `17px` | 品牌、关键数字 |
| `--font-size-xl` | `20px` | 基础设施页面标题 |

- 字重使用 `400` / `500` / `600` / `700`；不要使用 300 以下的细字重。
- 正文行高 1.5–1.7；紧凑列表可以用 1.4。
- 代码、路径、需求 ID 使用等宽字体栈：`ui-monospace, "Cascadia Code", monospace`。

### 阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `--shadow-card` | `0 3px 14px rgba(30, 41, 59, .025)` | 普通卡片，几乎不可见 |
| `--shadow-popover` | `0 12px 32px rgba(15, 23, 42, .12)` | 弹窗、抽屉、浮层 |

- 不使用大面积彩色阴影；主按钮 hover 的轻微投影可以保留。
- 卡片靠边框和背景区分层级，不靠重阴影。

## 3. 组件库使用边界

| 来源 | 用法 | 约束 |
| --- | --- | --- |
| FancyUI（`fancy-ui-vue`） | 通用交互控件，当前用于 `Switch` | 从包导入组件；全局样式已在 `style.css` 引入；新增组件前先确认包内确实提供 |
| Ease UI（源码副本） | `XlyButton` 用于页面操作按钮 | 只从 `src/components/xly-button` 导入；不要从主应用跨项目导入；复制新组件时保留来源说明 |
| Element Plus 图标 | `@element-plus/icons-vue` | 只用于图标，不引入 Element Plus 组件、主题或完整 CSS |
| Tailwind CSS | 简单布局、间距、响应式工具类 | 不与 scoped CSS 写同一属性的冲突值；复杂视觉优先 scoped CSS + Token |

- 同一视图里不要混用两套主按钮风格。主操作统一用 `XlyButton`。
- 一个视图只保留一个视觉上的主按钮；次要操作使用 `ghost` 或 `text`，危险操作使用 `danger`。
- 图标尺寸 12–18px，与文字间距 6–8px；不要用 emoji 充当图标。

## 4. 页面布局

- 页面结构：顶部工具栏（搜索、筛选、主操作）→ 统计/摘要（可选）→ 内容区（列表、卡片、表格或分栏）。
- 工具栏左侧放当前视图名称和数量，右侧放操作；不要把主操作放在页面底部。
- 设置类页面内容宽度不超过 980px；数据列表可以使用更宽布局，但不要横向铺满超宽屏。
- 卡片网格使用 16–20px 间距；卡片内部按「标识/状态 → 标题 → 描述 → 元信息 → 操作」组织。
- 分栏详情页左侧列表宽度 240–320px，右侧内容自适应；移动端改为上下堆叠。
- 响应式断点沿用现有外壳：900px（侧栏抽屉）、680px（紧凑单列）。

## 5. 玻璃质感

- 只允许用在外壳顶栏、粘性工具条、遮罩层和浮层背景。
- 最大模糊半径 14px；透明度要保证文字对比度，不能牺牲可读性。
- 不要给普通卡片、表格、表单、列表行加玻璃效果；不要叠加多层玻璃。
- 必须提供不依赖 `backdrop-filter` 的可见背景色作为降级。

## 6. 状态与反馈

- 空状态：图标 + 一句说明 + 一个明确操作（如「新建需求原型」）；不要只写「暂无数据」。
- 加载状态：超过 300ms 的操作用 spinner 或骨架；不要把空白页当成加载中。
- 错误状态：说明发生了什么、影响范围和一个可执行的下一步；不要显示堆栈或内部路径。
- 成功反馈：短 toast 或行内状态变化；不要用 `window.alert`。
- 危险操作：必须二次确认，确认按钮使用 `danger`，文案写清对象和后果。

## 7. Mock 数据与演示态

- Mock 数据只放在需求目录内（页面同级或 `components/`），不进入 `src/components/` 公共组件。
- 数据必须确定、可重复，不使用真实令牌、真实客户信息或外部接口。
- 页面明显是演示态时，在工具栏加一个低对比的「演示数据」标记；不要让用户误以为是真实业务数据。
- 模拟操作要给出真实反馈（toast、状态变化、空状态），不要点击后毫无反应。
- 除非页面本身在演示持久化，否则刷新后重置；需要 `localStorage` 时使用带需求前缀的 key，不能复用外壳的 `prototype-workbench-visible-pages`。

## 8. 可访问性与细节

- 所有可点击元素有 `:focus-visible` 样式；不要移除浏览器焦点轮廓而不提供替代。
- 图标按钮必须有 `aria-label`；开关必须有可读的 `label`。
- 支持键盘操作；弹窗打开后焦点进入弹窗，关闭后回到触发元素。
- 尊重 `prefers-reduced-motion`，动画不超过 250ms，不做无限循环装饰动画。
- 移动端可点击区域不小于 36px；表格在窄屏允许横向滚动，不压缩到不可读。
